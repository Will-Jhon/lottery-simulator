# 🎰 本地双色球模拟器

> 现实中不了奖，网上也难中奖咯。
> 那不如……在自己的电脑里过把瘾？反正这里的五百万不要钱。

一个本地双色球模拟器：49 个球在摇奖机里翻滚，中奖球一颗一颗掉出来，
跟电视上一模一样——唯一的区别是，这里不用交两块钱智商税。

**两个版本，随你翻牌：**

| 版本 | 目录 | 技术栈 | 打开方式 |
|------|------|--------|----------|
| 🖥️ 桌面版 | `src/` | Java Swing | 双击 `run.bat` |
| 📱 手机版 | `mobile/` | HTML5 + Canvas + PWA | 双击 `mobile/serve.bat`，手机连同一 WiFi 访问 |

手机版可以"添加到主屏幕"，像真 App 一样全屏使用，还支持离线玩。

## ✨ 功能

- 🎉 **电视同款开奖动画**：33 个红球 + 16 个蓝球在玻璃奖仓里被鼓风机吹得满天乱窜，
  开奖时中奖球被吸入出球口，沿漏斗滑落，"啪"地一声掉进展示槽，还带弹跳和金光
- 🎵 **沉浸式音效**：搅拌轰鸣、出球"嗖"、落球"啵"、中奖还有一段催泪小旋律
  （没有音响也不慌，程序会装作无事发生）
- 🛒 **买彩票**：机选一注 / 机选五注 / 自选一注（33 红选 6、16 蓝选 1 的选号盘，
  手气差可以让"机选填充"替你背锅）
- 💰 **看看能中多少**：命中号码自动标金圈，一等奖 500 万、二等奖 30 万，
  三到六等奖跟真实奖金一致——虽然中奖概率也跟真实的一样感人
- 📊 **严肃的统计面板**：余额、累计投入、累计奖金、净收益、最佳单期，
  用数据告诉你什么叫"期望值为负"
- ⏭️ **跳过动画**：人生苦短，等不及可以直接快进到心碎

## 🎮 快速开始

### 🖥️ 桌面版（Java Swing）

#### 方式一：双击 run.bat（推荐）

```bat
run.bat
```

自动编译 + 启动，无需安装任何第三方库，只需要 **JDK 8+**。

#### 方式二：IntelliJ IDEA

直接用 IDE 打开本目录，运行 `lottery.Main`。

#### 方式三：手动编译

```bash
javac -encoding UTF-8 -d out @sources.txt   # 或一次性编译 src 下所有 java
java -Dfile.encoding=UTF-8 -cp out lottery.Main
```

### 📱 手机版（Web App / PWA）

#### 方式一：局域网访问（推荐，可安装到主屏幕）

```bat
mobile\serve.bat
```

启动后脚本会打印一个地址（如 `http://10.96.230.114:8080`），
手机连**同一个 WiFi** 后用浏览器打开即可。然后用浏览器菜单的
**"添加到主屏幕"**，它就是个假 App 了（还真能离线玩）。

> 服务器是 JDK 自带能力写的（`mobile/Serve.java`），零第三方依赖。
> 想换端口：`java -cp mobile Serve 9090`。

#### 方式二：直接打开

直接把 `mobile/index.html` 拖进手机/电脑浏览器也能玩
（文件方式不支持"添加到主屏幕"和离线缓存，其它功能都一样）。

#### 方式三：打包成单文件发给朋友（推荐）

双击 `mobile\build-single.bat`，生成 `mobile\dist\双色球模拟器.html`（约 65KB），
**通过微信/QQ/邮件直接发给朋友，对方点开即玩**——零安装、零配置。

## 🕹️ 使用说明

1. 点【机选一注】或【自选一注】买几注（每注 ¥2，初始余额 ¥100，破产了可以点【领零花钱】）
2. 点大字【开 始 摇 奖】，搬好小板凳看球一颗一颗掉出来
3. 开奖后右侧列表会标出每注的命中情况和奖级，顶部统计你的"辉煌战绩"
4. 心动了就再来一期，心碎了就……再来一期

## 🧾 规则（和现实一样，别想着蒙混过关）

| 奖级 | 命中条件 | 奖金 |
|------|----------|------|
| 一等奖 | 6 红 + 1 蓝 | ¥5,000,000 |
| 二等奖 | 6 红 + 0 蓝 | ¥300,000 |
| 三等奖 | 5 红 + 1 蓝 | ¥3,000 |
| 四等奖 | 5 红 + 0 蓝 或 4 红 + 1 蓝 | ¥200 |
| 五等奖 | 4 红 + 0 蓝 或 3 红 + 1 蓝 | ¥10 |
| 六等奖 | 蓝球命中（红球 0~2 个） | ¥5 |

红球从 1-33 里开 6 个，蓝球从 1-16 里开 1 个，每期号码完全随机（`SecureRandom` 签发，童叟无欺）。

## 📁 项目结构

```
lottery-simulator/
├── run.bat                    # 桌面版一键启动
├── src/lottery/               # 桌面版（Java Swing）
│   ├── Main.java              #   入口
│   ├── model/                 #   模型层（球、彩票、开奖结果、奖级、摇奖机）
│   ├── ui/                    #   界面层（摇奖机动画、主窗口、选号对话框……）
│   └── util/Sound.java        #   音效合成器（正弦波手搓，零依赖）
└── mobile/                    # 手机版（Web App / PWA）
    ├── index.html             #   页面
    ├── css/style.css          #   移动端暗色主题
    ├── js/lottery-core.js     #   核心逻辑（纯函数，Node 可测）
    ├── js/app.js              #   UI + Canvas 摇奖机动画
    ├── manifest.json / sw.js  #   PWA 清单 / 离线缓存
    ├── Serve.java / serve.bat #   零依赖静态服务器 + 一键启动
    ├── build-single.js/bat    #   打包成单文件（发给朋友用）
    ├── test/core.test.js      #   核心逻辑测试（node mobile/test/core.test.js）
    └── dist/                  #   打包产物（单文件版，git 忽略）
```

两个版本共用一套玩法与规则，动画同款：49 球翻滚搅拌 → 中奖球吸入出球口 → 掉入展示槽。
