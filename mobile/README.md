# 📱 双色球模拟器 · 手机版

> 现实中不了奖，网上也难中奖咯——但蹲坑时来一发，只要 3 秒。

桌面版的移动端移植：纯 HTML5 + Canvas + PWA，**零依赖、零安装**，
手机浏览器打开即玩，还能"添加到主屏幕"伪装成原生 App（真的，连图标都有）。

## 🚀 怎么打开

### 方式一：serve.bat（推荐）

双击 `serve.bat`，它会：

1. 用 JDK 自带的 HttpServer 编译并启动一个静态服务器（`Serve.java`，零第三方库）
2. 打印一个局域网地址，比如：

```
手机访问 : http://10.96.230.114:8080  (需同一 WiFi)
```

3. 手机连**同一个 WiFi**，浏览器打开这个地址
4. 浏览器菜单 → **添加到主屏幕**，之后就能全屏 App 一样打开，且支持离线

> 换端口：`java -cp . Serve 9090`（需先在 mobile 目录编译过 Serve.java）

### 方式二：直接拖文件

把 `index.html` 拖进任意现代浏览器（手机/电脑都行）就能玩。
文件方式下"添加到主屏幕"和离线缓存不可用，其它功能完全一致。

## 🎮 玩法

1. 底部【机选一注】/【机选五注】/【自选一注】买票（每注 ¥2，初始余额 ¥100，右上角 💰 领零花钱）
2. 点大字【开 始 摇 奖】，49 个球开始翻滚，中奖球一颗一颗掉进展示槽
3. 开奖后自动算奖：命中号码标金圈、显示奖级，中奖放一段旋律
4. 等不及了点【跳过动画】直接快进到心碎

顶部统计：期号 / 余额 / 累计投入 / 累计奖金 / 净收益 / 最佳单期，
数据存在浏览器 localStorage 里，关掉页面不丢。

## 🗂 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 页面骨架 |
| `css/style.css` | 移动端暗色主题（安全区适配、底部抽屉、触摸优化） |
| `js/lottery-core.js` | 核心逻辑纯函数：摇奖、奖级判定、格式化（浏览器/Node 双端） |
| `js/app.js` | UI 交互 + Canvas 摇奖机动画（物理引擎同桌面版） |
| `manifest.json` | PWA 清单（名称、图标、全屏启动） |
| `sw.js` | Service Worker，缓存静态资源实现离线可用 |
| `Serve.java` | 零依赖静态服务器（JDK8 `com.sun.net.httpserver`） |
| `serve.bat` | 一键编译并启动服务器 |
| `icons/` | PWA 图标（192/512） |
| `test/core.test.js` | 核心逻辑测试：`node test/core.test.js` |
